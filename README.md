In this code we're using doubly linked list to sort through a flight reservation system that should assist an airline in adequately sorting through passengers of a flight. 

Doubly linked list uniquely allows the user to:
*Traverse forward and backward throughout the list
*Efficient deletion and insertion using at any location in the list
*Maintained sorting order, even if the system is asked to display the passengers in ascending or descending order.

There are 'dummy' passengers in the list to showcase the usability of the code. We can add and remove specific passengers. When adding, you're prompted to state users name, the class of the ticket they would like to reserve, and their assigned boarding group for that class. After submitting this information the passenger is officially sorted into the reservations list. Removing a passenger by simply entering a passengers name, if they exist in the list. All of the passengers in the list can be displayed in either ascending order or descending order.
